MR ERROR | Phone Information Checker

1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run: npm install
4. Copy .env.example to .env
5. Put your NumVerify API key in .env (never in index.html).
6. Run: npm start
7. Open: http://127.0.0.1:3000

Use only phone numbers you own or are authorized to check. This app provides number metadata such as validation, country/region, carrier, line type and formats. It does not provide private identity, passwords, OTPs, account access, or live location.
